# acn — доказательный компилятор

Нативный компилятор языка acn. Само-хостится до машинного кода (x86-64 PE) без внешних инструментов
(C, gcc, Python).

## Системные требования

- Windows x86-64
- ~4 ГБ свободной ОЗУ (само-компиляция потребляет ~3.4 ГБ)

## Установка

```bash
git clone https://github.com/nedsandr/acn.git
cd acn
```

Репозиторий содержит готовый `acn.exe`. Дополнительная установка не требуется.

## Использование

Входной файл должен содержать точку входа `main : Nat`.

Конфигурация сборки — `buildcfg.txt` (две строки: путь к исходнику, путь к выходному `.exe`).

По умолчанию собирает `examples/fact.acn` → `out/fact.exe`:

```cmd
.\acn.exe
.\out\fact.exe
echo %errorlevel%   :: 120
```

## Гарантии верификации (0.1)

Программа, принятая судьёй, обладает следующими свойствами:

- **Тотальность** — все функции структурно рекурсивны (не зацикливаются).
- **Типобезопасность** — типы аргументов аппликаций и ветвей `case` согласованы.
- **Исчерпываемость** — `case` покрывает все конструкторы индуктивного типа.

Это исключает класс ошибок: необработанные случаи, несогласованность типов ветвей,
неструктурная рекурсия.

**Не гарантируется:** семантическая корректность сверх типовой спецификации (функция может иметь
корректный тип, но не соответствовать намерению программиста).

## Само-хостинг

Исходники компилятора: `src/*.acn`. Точка входа: `src/builder.acn`.

Воспроизводимость:

1. В `buildcfg.txt` указать `src/builder.acn` и путь к новому бинарю.
2. Запустить `acn.exe`.
3. Результат байт-в-байт идентичен исходному `acn.exe`.
